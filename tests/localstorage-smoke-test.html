How to use this test
  1. Open this file in HTML Viewer Q. Note the "Visit counter" value below.
  2. Fully background the app (Home button / swipe up), wait a few seconds, then reopen it — do not re-tap the file, just bring the app back to foreground. Reload this same screen if needed and check the counter stayed the same (didn't reset) and "Stored value found" still shows the same timestamp.
  3. Force-quit HTML Viewer Q entirely (swipe away in the App Switcher), then reopen the app and re-navigate to this same file. Check again.
  4. As the toughest test: re-import this exact file into HTML Viewer Q via Files/iCloud Drive again (as if it were updated), then open it. Check whether the counter/timestamp survived or reset to zero/missing.

If the value survives steps 2–3 but resets on step 4, that tells us localStorage persists across app restarts but NOT across re-importing the file — useful either way, since the real game will rarely be re-imported mid-match.
